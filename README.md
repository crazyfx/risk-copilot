# Risk Copilot

Early stage: idea and design, v0.1 in development.

A read-only MCP server that adds a risk layer on top of the MyFundedPerps API: distance to loss floors, safe position sizing, pre-trade checks and execution-quality reports.

Planned for v0.1: `risk_status`, `position_size`, `pre_trade_check`.

Built and tested in the sandbox first. It never places orders.

Not official MyFundedPerps software.
